# Buster Build Warning Template Update — 17 October 2026

This update applies the revised disciplinary warning PDF structure to Buster Build only.

## Buster Build warning PDF now includes
- Employee full name & surname
- Employee number
- Job title
- Department
- Date issued
- Expiry date
- Nature of offence
- Short description
- Standard six-month disciplinary procedure and appeal notice on every warning level
- Manager signature, name in print and date
- Employee statement / comments / remarks
- Employee signature, name in print and date
- Witness signature, name in print and date

## Hub behaviour
- When a Buster Build warning is opened, the expiry date defaults to six months after the date issued.
- Changing the Buster Build warning issue date automatically recalculates the six-month expiry date.
- Existing Verbal, Written and Final written warning levels remain available.
- Other workspaces retain their existing PowerBuild warning PDF template.
- No database migration is required. Existing warning fields are reused.
