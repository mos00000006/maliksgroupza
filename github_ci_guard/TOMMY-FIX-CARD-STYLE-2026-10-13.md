# Tommy Fix card style cleanup — 13 October 2026

Refined the Company Hub catalogue styling for the expanded Tommy Fix fastener variants.

## What changed
- Tommy Fix cards now use a cleaner fastener-focused visual style.
- Long variant descriptions are replaced with two compact fields: **SIZE** and **PACK**.
- Product names are limited to two neat lines so cards stay aligned.
- Product code badges remain visible for each individual Tommy Fix code.
- Added cleaner spacing and mobile sizing so the larger number of variants still looks organised.
