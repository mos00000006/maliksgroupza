# Catalogue Kitchens Category — 20 October 2026

Kitchens is now handled as a normal catalogue category rather than a separate kitchen/promotion prompt.

## Changes
- Added **Kitchens** to the standard catalogue category list.
- Added a normal category navigation bar to **Our Catalogue**.
- Kitchens can be selected exactly like Plumbing, Paints & Allied, Tools, Homeware, etc.
- Added **Kitchens** to the Add/Edit Product category dropdown.
- Added server-side category filtering so clicking Kitchens only loads Kitchens products.
- Added Kitchens to the wholesale PDF category ordering.
- The separate kitchen callout/banner is not part of this catalogue screen.

Typical Kitchens products can now be saved normally under the Kitchens category, including kitchen sinks, sink taps, sink fittings, kitchen tiles and related products.

No database migration is required.
