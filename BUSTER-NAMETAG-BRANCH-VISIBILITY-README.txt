BUSTERBUILD NAME TAG - BRANCH / SPECIALITY VISIBILITY UPDATE
===========================================================

This update improves the visibility of the third line on the BusterBuild salesperson name tag
(for example: "Plumbing specialist").

What changed
------------
- Increased text size for the branch / store / speciality line on BusterBuild name tags.
- Increased font weight.
- Changed the colour to a brighter off-white for stronger contrast.
- Tightened spacing so it sits better under the role line.
- Added a subtle shadow so the text remains readable in the JPG/PDF export.

File included
-------------
- app/price-tags/staff-card-studio.module.css

How to apply
------------
Replace the matching CSS file in your project and redeploy.
