# Lucide attribution

This Maliks POS user interface bundles the original SVG geometry for selected Lucide icons from https://github.com/lucide-icons/lucide.

Project: Lucide — https://lucide.dev
Licence: ISC (see https://github.com/lucide-icons/lucide/blob/main/LICENSE)

The selected icons are self-hosted as static SVG strings in `maliks-operations/src/pos-lucide-icons.mjs`. They are not generated, approximated or fetched from external CDNs at runtime.
