# Employee Payslip — Fuller Employment Details (2026-10-16)

The PowerBuild payslip PDF has been expanded so it looks fuller and contains more important employment information without adding unnecessary deductions.

## Added automatically to the PDF
- Employment start date
- Length of service (calculated automatically)
- Employment status
- Supervisor / manager
- Mobile / WhatsApp
- Employee email
- Pay cycle (derived from the pay period)

## Existing important information retained
- Employee name and number
- Branch / workspace
- Job title
- Department
- Employment type
- Pay period
- Payment date and method
- Payment reference
- Gross earnings
- UIF / loan / other deductions
- Net pay
- Payroll notes
- Payslip number and confidential payroll footer

No database migration is required. The information is pulled from the existing employee file and payslip record.
