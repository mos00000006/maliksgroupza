NAME TAG A4 SHEET UPDATE
========================

This update adds an A4 sheet builder to the Salesperson Name Tag tool.

What is included
----------------
- Add each name tag to an A4 queue instead of downloading one by one.
- Choose 6 tags per A4 or 8 tags per A4.
- Preview the A4 page before downloading.
- Download one A4 PDF or one A4 JPG.
- Keep the existing single-tag PDF and JPG downloads.
- Keeps the earlier branch/speciality visibility improvement on BusterBuild name tags.

How to use
----------
1. Open Price Tag Studio.
2. Choose Salesperson name tags.
3. Enter the staff details.
4. Click "Add to A4 sheet".
5. Enter the next staff member and add again.
6. Choose either 6 tags per A4 or 8 tags per A4.
7. Download the A4 PDF or A4 JPG.

Files included
--------------
- app/price-tags/staff-card-studio.tsx
- app/price-tags/staff-card-studio.module.css
- app/lib/staff-card-export.ts
- this README

Notes
-----
- The A4 sheet builder is for Salesperson name tags.
- The single-tag exports still work.
- Business cards remain single export only.
- Existing live deployment is not changed until you replace these files and redeploy.
