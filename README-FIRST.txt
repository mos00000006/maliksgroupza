POWERBUILD PUBLIC WEBSITE — LEROY MERLIN–INSPIRED DESIGN + LIVE MALIKS HUB CATALOGUE

WHAT THIS IS
A single cumulative patch for the original Maliks Group Hub ZIP supplied in this chat. It replaces BOTH prior PowerBuild website ZIPs; do not apply those first. This is an original PowerBuild design, not a copy of Leroy Merlin branding or code.

FILES INCLUDED
- app/ecommerce-storefront.tsx — branded retail storefront and unchanged wholesale functionality
- app/ecommerce-storefront.module.css — full desktop/tablet/mobile storefront styling
- app/api/ecommerce/public/route.ts — public retail catalogue feed and existing order API
- app/api/ecommerce/product-image/[id]/route.ts — product image delivery
- app/api/ecommerce/control/route.ts — E-Commerce Control integration
- app/ecommerce-control.tsx — Hub management links
- app/page.tsx — View Website link in Hub
- tests/powerbuild-live-storefront.test.mjs — lightweight code check

INSTALL
1. Back up the current GitHub repository and Cloudflare D1 database.
2. Unzip and copy the app/ and tests/ folders into the repo, preserving relative paths.
3. Commit; run npm run check in the FULL repository (this ZIP is a patch, not standalone project).
4. Deploy through the existing workflow. Customer site route: /shop. Wholesale portal: /wholesale-shop.
5. Make public only /shop, /api/ecommerce/public GET and necessary public product/special image GET routes in Cloudflare Access. All Hub/admin and editing APIs MUST remain restricted. Check route behavior before switching traffic.
6. Ensure store photos, prices and published specials exist in Hub; absent images will show the fallback. E-Commerce Control manages explicit publication and pricing.
7. To use a separate public domain, first confirm domain ownership/registration, connect via Cloudflare DNS and route mapping, and verify SSL + authentication boundaries. No domain has been purchased or configured by this patch.

FEATURES
- Retail homepage with large hero, unified search, departments, specials, product grid, responsive layout
- Products synced on next fetch from the Hub catalogue; newly active products default to appearing in retail unless explicitly B2C-disabled. Public publishing should be reviewed in E-Commerce Control before deployment.
- Shopping cart, order submission, branch collection/delivery preference and order status lookup
- Retail price displayed when entered; otherwise Price on request. No online card payment gateway or real-time stock reservation.
- B2B remains approved account only, separate wholesale pricing and security
- Product images reflect existing Hub data; missing photos cannot be generated by the sync.

IMPORTANT
- No live deployment or domain activation performed.
- Full build and Cloudflare live tests remain to be run on the actual repository/environment.
- Please review product publication carefully: the feed includes active products by default; explicitly disable any private or incomplete product before opening public site.
