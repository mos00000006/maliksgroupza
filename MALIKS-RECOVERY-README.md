consolidated from the last full project snapshot plus all approved patches up to
16 September 2026.

- Safari/iPhone Home Screen notification support
- Complete/approval/return-to-work workflow
- Catalogue with image upload, search, admin controls and card styling
- AI Sidekick API integration
- Mobile Quick Actions

- Daily Manager Checklists
- Executive Store Ranking / Store Control Centre
- Employee Records

removed at the user's request.

Settings > Secrets and variables > Actions.
